## **Overview**
This project is a Xonix-inspired game developed using C++ and SFML. It recreates the core gameplay where the player captures areas while avoiding moving enemies.

The project focuses on implementing game logic, rendering, and real-time interaction using a lightweight graphics library instead of a full game engine.

## **Features**
- Real-time 2D gameplay using SFML  
- Player movement system  
- Area capturing mechanics  
- Enemy movement  
- Collision detection  
- Game loop (update, render, input handling)  
- Game over and restart system
